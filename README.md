# Irish-weather-R-app-data-from-Met-ireann-
Visualise historical data from Met Éireann. Any weather station, any weather metric, either bar or line graphs. Includes R shiny app for graphical user interface to produce graphs

Data source: https://www.met.ie/ga/climate/available-data/historical-data
Download daily data series from weather station of your choice.

Dunsany, Co. Meath weather station data is provided here - May 2006 to January 2026
